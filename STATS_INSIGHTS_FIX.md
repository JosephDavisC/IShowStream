# Stats, Insights, and Streamer Info Fix

## Issues Fixed

### 1. ✅ Channel Name Normalization
**Problem**: Channel names in Firestore are stored with "#" prefix (e.g., "#xqc"), but queries were not handling this consistently.

**Solution**: 
- Created `normalizeChannel()` function that ensures channel names always have "#" prefix for Firestore queries
- Removed "#" prefix when calling Twitch API (API doesn't use it)
- All endpoints now normalize channel names before querying

### 2. ✅ Streamer Info Endpoint
**Problem**: `getStreamerInfo` only read from environment variable, not from query parameter.

**Solution**:
- Updated to accept channel from query parameter
- Added proper error handling and logging
- Removed "#" prefix before calling Twitch API
- Added timeout for API calls

### 3. ✅ Insights Endpoint
**Problem**: Insights endpoint didn't filter by channel.

**Solution**:
- Added channel filtering to insights endpoint
- Supports query parameter: `?channel=channelname`
- Falls back to environment variable if not provided

### 4. ✅ Frontend Channel Filtering
**Problem**: Frontend wasn't passing channel parameter to all endpoints.

**Solution**:
- Updated all API calls to include channel parameter
- Added channel filtering to stats, insights, and streamer info endpoints
- Added better error logging

## Channel Name Format

### In Firestore:
- Channels are stored with "#" prefix: `#xqc`, `#ninja`, etc.
- All queries now normalize to this format

### In User Input (Profile):
- Users can enter channel with or without "#" prefix
- System normalizes automatically

### In Twitch API:
- Twitch API doesn't use "#" prefix
- System removes "#" before API calls

## API Endpoints Updated

### `/api/stats`
- Accepts `?channel=channelname` query parameter
- Filters messages by channel
- Returns stats for the specified channel

### `/api/insights/latest`
- Accepts `?channel=channelname` query parameter
- Filters insights by channel
- Returns latest insight for the specified channel

### `/api/streamer`
- Accepts `?channel=channelname` query parameter
- Fetches streamer info from Twitch API
- Returns display name and avatar URL

### `/api/messages/recent`
- Already had channel filtering (fixed in previous update)
- Normalizes channel name for consistent queries

## Common Issues

### Issue: Stats showing 0 messages
**Possible Causes**:
1. **No messages in Firestore**: Check if messages exist for the channel
2. **Channel name mismatch**: Verify channel name matches exactly (case-insensitive, but "#" prefix matters)
3. **Messages older than 1 hour**: Stats only count messages from last hour
4. **No agent_analysis field**: Stats require messages to have `agent_analysis` field

**Debugging**:
1. Check browser console for stats API response
2. Check backend logs for query results
3. Verify messages exist in Firestore for the channel
4. Verify messages have `agent_analysis` field

### Issue: Insights not showing
**Possible Causes**:
1. **No insights generated**: Insights are generated by the insight processor
2. **Channel name mismatch**: Verify channel name matches
3. **No insights for channel**: Insights might be for a different channel

**Debugging**:
1. Check browser console for insights API response
2. Check backend logs for query results
3. Verify insights exist in Firestore for the channel
4. Check if insight processor is running

### Issue: Streamer info not showing
**Possible Causes**:
1. **Missing Twitch API credentials**: Check `TWITCH_CLIENT_ID` and `TWITCH_CLIENT_SECRET`
2. **Invalid channel name**: Channel doesn't exist on Twitch
3. **API rate limiting**: Twitch API might be rate limiting requests
4. **Network issues**: Can't reach Twitch API

**Debugging**:
1. Check browser console for streamer API response
2. Check backend logs for Twitch API errors
3. Verify Twitch API credentials are set
4. Verify channel name is correct

## Firestore Index Requirements

### Required Indexes:
1. **Messages Collection**:
   - `channel` (Ascending) + `timestamp` (Descending)
   - `channel` (Ascending) + `timestamp` (Ascending) [for stats]

2. **Insights Collection**:
   - `channel` (Ascending) + `timestamp` (Descending)

### Creating Indexes:
Firestore will automatically prompt you to create indexes when needed. Click the link in the error message to create the index.
