# Logo Setup Instructions

## Adding Your Logo

1. Place your logo SVG file in the `public/` directory
2. Name it `logo.svg`
3. The logo will automatically be used for:
   - Browser tab favicon
   - Navbar logo (top-left corner)
   - PWA app icons

## File Location

```
frontend/dashboard/public/logo.svg
```

## Recommended Logo Specifications

- **Format**: SVG (Scalable Vector Graphics)
- **Size**: Vector format scales to any size
- **Background**: Transparent (recommended for dark themes)
- **Aspect Ratio**: Square (1:1) recommended

## Notes

- SVG format provides crisp display at any size
- The logo should work well on both light and dark backgrounds
- For best results, use a logo with good contrast
- The navbar logo will be displayed at 32px height
- The favicon will be displayed at various sizes by the browser
- SVG files are typically smaller and scale better than raster formats
